# Privacy Policy — Automatic Job Apply

This is a personal, self-hosted tool used only by its owner. It is not offered to other users.

**Google user data accessed:** the tool uses the Gmail API only on its owner's own account to
create email drafts, send emails the owner has approved, send the owner a daily summary, and read the
status (sent / deleted) of drafts it created.

**Storage:** data stays on the owner's own computer and in the owner's private GitHub repository.
OAuth tokens are stored locally or as encrypted GitHub Actions secrets.

**Sharing:** no Google user data is sold, shared with third parties, or used for advertising or
for training AI models. Email drafts are written with the Google Gemini API from the owner's resume
and public job postings; no Gmail content is sent to Gemini.

**Deletion:** the owner can revoke access at any time at https://myaccount.google.com/permissions
and delete the local data folder.
